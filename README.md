# Файлдар қызметі

PostgreSQL базасымен жұмыс істейтін файлдар қызметіне деректерді тексеру, қателерді орталықтан өңдеу және сұраныстарды журналдау қосылды. Қолданба мен база күйін бөлек тексеру іске асырылды. Құпия баптаулар кодтан бөлек сақталады. База қосылымындағы ақау тексеріліп, қалпына келтірілді.
